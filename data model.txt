example 

role: "national"
jurisdictionType: "all"
jurisdictionId: null

or 

role: "province"
jurisdictionType: "province"
jurisdictionId: <Western Province ID>

or 

role: "district"
jurisdictionType: "district"
jurisdictionId: <Colombo District ID>

National user  → all data
Province user  → own province
District user  → own district

| Role                | What they can read                                                             |
| ------------------- | ------------------------------------------------------------------------------ |
| **National User**   | All provinces → all districts → all substations → all installations → readings |
| **Provincial User** | Only their assigned province(s)                                                |
| **District User**   | Only their assigned district (s)                                                   |
